# Pothole Detection and Road Damage Assessment

An AI-based pothole detection prototype using deep learning and computer vision.

## Tech Stack
- Python
- YOLOv8
- OpenCV
- Google Colab
- Streamlit (planned)

## Current Features
- YOLOv8 model training
- Pothole detection from road images
- Bounding-box visualization
- Confidence score output

## Current Progress
The YOLOv8 model has been trained for 20 epochs and tested on sample images. Pothole detection with bounding boxes is working.

## Upcoming Features
- Model evaluation
- Severity estimation
- Streamlit dashboard
- Video-based pothole detection
- Detection reports and analytics

## Running the Notebook
Open `Pothole_Detection.ipynb` in Google Colab and follow the notebook cells.

## Disclaimer
This is an academic prototype. Severity estimation and real-world performance require further validation.
